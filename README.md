# Calculator_App

A  Calculator app that allows users to perform basic arithmetic operations as well as exponentiation and modulus. 

---

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Exponentiation (`^`)
- Modulus (`%`)
- Increment and decrement buttons for both numbers
- Reset all functionality
- Clean green/black UI theme
